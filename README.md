# coming-soon

A React + TypeScript single-page “Coming Soon” experience with an animated terminal intro and motion-based UI transitions.

## Stack

- React 19
- TypeScript
- Vite+
- Tailwind CSS
- Motion

## Getting started

```bash
vp install
vp dev
```

## Available commands

```bash
vp dev      # start local dev server
vp build    # type-check and build production assets
vp lint .   # run lint checks
vp preview  # preview production build locally
vp check    # run formatting + lint + type checks
vp test     # run tests (if present)
```
